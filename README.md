# Sistema de Gerenciamento de E-commerce

Aplicação em Java desenvolvida para simulação e gerenciamento de operações essenciais de um e-commerce.

## 🛠️ Tecnologias Utilizadas
- Java
- Programação Orientada a Objetos (POO)
- Estruturas de Dados

## 📌 Funcionalidades
- Cadastro e gerenciamento de produtos e estoque.
- Processamento de pedidos e regras de negócio de vendas.
